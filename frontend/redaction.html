Why this is the last gate, not the first

Redaction runs on content the agent has already decided to send. It cannot tell whether the agent was tricked — only whether what it is about to emit contains something protected. That makes it the backstop behind tool policy, not a substitute for it: an action that was never authorised never produces output to redact.
